# ADR-001

Используем CPAL вместо Rodio.

Причина:
- минимальная задержка;
- полный контроль над callback;
- одинаковый API для записи и воспроизведения.

---

# ADR-002

Используем rtrb.

Причина:
- SPSC;
- lock-free;
- без аллокаций.

---

# ADR-003

Все аудиоданные передаются через FramePool и FrameId.

Причина:
- отсутствие копирования;
- отсутствие аллокаций.
